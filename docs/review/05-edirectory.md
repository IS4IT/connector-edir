# 05 — eDirectory package

`com.evolveum.polygon.connector.ldap.edirectory` (5 files, 821 lines)

## Summary

The package is small and the template-method fit against `AbstractLdapConnector` /
`AbstractSchemaTranslator` is sound, but the eDirectory-specific semantics on top of it have
several concrete holes. The reciprocal group handling can leave the directory permanently
inconsistent on a partial failure, and it silently does nothing at all for group object classes
derived from the configured one — the mirror image of the bug that commit `0d9d63f` fixed on the
user side. `__LOCK_OUT__` is computed from an attribute the connector never asks the server for,
so locked accounts read back as unlocked on the code path midPoint actually uses. The
`__ENABLE__` mapping is fail-open on an empty delta and its filter translation disagrees with its
own read translation about what a missing `loginDisabled` means. Two of the three Novell syntaxes
that `toConnIdType` declares as `byte[]` are missing from `isBinarySyntax`, which corrupts values
on write. Finally, `discoverConfiguration()` — including a 22-line commented-out block — is dead:
the connector no longer implements `DiscoverConfigurationOp`, so ConnId never calls it.
